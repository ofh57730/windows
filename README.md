# 雾锁王国服务器租用：按人数倒推配置，Windows 专属服从下单到进游戏一次说清

《雾锁王国》（Enshrouded）最劝退的时刻，往往不是被雾追着跑，而是周末晚上四个人想一起盖房子，结果公共服卡得连箱子都打不开。自己租一台专用服务器能解决这个问题，但大部分人卡在第一步：不知道要买多大，也怕买错。

这篇按你的实际联机人数把配置算清楚，再把租用流程、端口、存档和常见坑一次讲完。中间会以国产云服务商雨云的游戏云机型作为价格参照——它官网本身就带雾锁王国的 Windows 搭建文档，拿来对照比较省事。

## 先确认三个硬条件，不然买完用不了

**必须是 Windows。** 雾锁王国的专用服务器程序目前官方只支持 Windows，Linux 支持还在计划中。网上有些 Linux 开服教程可以直接跳过，照做大概率卡在启动那一步。腾讯云、百度智能云、京东云的官方部署文档也都写明了这个限制。

**端口是 UDP 15636 和 15637。** 15636 负责游戏通信，15637 是查询端口。只放行其中一个，结果通常是"服务端跑起来了，但朋友在服务器列表里搜不到"。少部分服务商的教程会建议 TCP、UDP 一起放行，稳妥做法是两个协议都开。

**内存按 16GB 起步规划。** 官方 FAQ 的数字是：服务器进程挂机约占用 4.4GB，每多一名在线玩家增加约 100MB，整个进程通常不超过 6GB。看起来 8GB 好像够用，但 Windows 系统本身、更新进程、备份和缓存都要吃内存，正式长期开服按 16GB 准备更省心。

## 配置怎么算：按人数倒推，别反过来

官方的参考规格其实分了档：

| 同时在线人数 | CPU 参考 | 内存 | 硬盘 | 上行带宽 |
| --- | --- | --- | --- | --- |
| 4–6 人 | 3.2GHz 级 i7，6 核 12 线程 | 16GB | 30GB SSD | 每人约 2 Mbps |
| 最多 16 人 | 3.7GHz 级 i7，8 核 16 线程 | 16GB | 30GB SSD | 每人约 2 Mbps |

这里面有两个数字最容易被忽略。

一个是单核主频。联机服务器的逻辑运算主要跑在主线程上，核心数堆得再多，主频上不去，人多了一样会拖影、掉帧。这也是为什么专做游戏服的服务商会特意标榜高主频 CPU，而不是单纯比拼核心数量。

另一个是硬盘空间。服务端解压后大约 13GB，官方建议预留 30GB，每多一个存档世界再占约 100MB。空间不够的典型症状是更新到一半失败，然后你对着一个半截的服务端目录排查半天。

至于 slotCount（最大玩家数），配置文件里的取值范围是 1–16。能填 16 不代表你的机器扛得住 16 个人，按实际同时在线人数买配置更实在。

## 租服务器时该看什么

便宜是好事，但雾锁王国这类生存建造游戏挑机器，优先级大概是这样的：

- **CPU 主频**，决定人多时会不会卡；
- **上行带宽**，决定玩家会不会瞬移、进不去图；
- **线路质量和防御**，公开服被压测是常事，被打一次全服回档的体验很差；
- **硬盘类型**，NVMe 固态能明显缩短进图和读档时间，机械盘开服玩家进门要等，这是能直接感受到的差别。

机房位置也值得看一眼。国内玩家多的话，选国内节点延迟更低，香港节点免备案但延迟和线路波动要自己权衡。

## 三档预算，对应三种开服场景

**两到四人小范围玩原版。** 4核8G 配 15M 带宽是能用的起点，Gold 6146 或 EPYC 7A23 这类机型月付折算下来在百元以内。注意官方给 4–6 人的参考规格是 6 核 12 线程加 16GB 内存，所以这个档位严格来说是"能跑但没余量"——建筑规模一大、或者有人开了大型模组，就得往上加。

**四到八人长期常驻。** 这是最常见的情况，建议 4核16G 加 15M 带宽，CPU 选高主频机型（7950X、14900K、9950X 这一档）。多花的钱主要在 CPU 主频上，换来的是高峰期不掉帧。

**十人以上的公开服。** 8核16G 往上，带宽按每人 2Mbps 往上堆，20M 起步比较稳，防御往 100G 以上看。公开服被压测的频率远高于朋友的私密服，别在这上面省。

## 从下单到进游戏，实际流程

1. 注册雨云账号并完成实名认证。未实名的账号无法购买产品。
2. 在游戏云里选 VPS 类机型，系统选 Windows 2019 或更高版本。雨云官方教程以 Windows 2019 为例；版本太老在安装阶段容易报错。
3. 拿到 IP 和登录信息，本地按 Win+R 输入 `mstsc` 打开远程桌面，连上去。
4. 下载 SteamCMD，运行后依次输入 `login anonymous` 和 `app_update 2278520 validate`，等下载完成。
5. 进入 `\steamapps\common\EnshroudedServer` 目录，双击 `enshrouded_server.exe`。首次启动后会生成 `enshrouded_server.json`，关掉窗口编辑这个文件，把服务器名称、密码、存档目录和 slotCount 改成你要的值。
6. 放行端口。云平台侧的安全组和 Windows 防火墙都要开 UDP 15636/15637。如果买的是 NAT 机型、没有独立公网 IP，还需要在管理页面配置端口转发，对应的两个端口也要同步改。
7. 进游戏。Steam 客户端里走「查看 → 游戏服务器 → 收藏」，添加 `你的IP:15637`；然后在库里启动雾锁王国，选「加入一局在线游戏」，收藏过的服务器会出现在列表顶部。

## 几个容易踩的坑

- **更新和开服是两件事。** 游戏版本更新后要重跑一次 `app_update 2278520 validate`，并且先结束 `enshrouded_server.exe` 进程，否则会提示文件被占用。
- **别只开一个协议。** 只放行 15636，部分玩家进不去；只放行 15637，服务器搜不到。
- **硬盘别卡着 30GB 买。** 存档随探索范围增长，留出余量比事后扩容省心。
- **带宽按人数乘 2Mbps 估。** 8 个人就是 16Mbps 上行，照这个数选档位比凭感觉买稳。

## 常见问题

**能用 Linux 开雾锁王国吗？**
官方目前只支持 Windows 专用服务器，Linux 支持还在计划中。网上流传的 Linux 方案多数不是官方支持路径，游戏更新后可能失效，还得自己维护。

**2 核 4G 能不能开？**
能启动、能进人。但官方给 4–6 人的参考是 6 核 12 线程加 16GB 内存，差距摆在那里。两个人小范围原版生存问题不大，人多或者建大型建筑就会明显吃紧。

**面板服和 VPS 该选哪个？**
雾锁王国没有预置的一键镜像，需要自己装 Windows 服务端，所以选 VPS 类型、系统装 Windows 更直接。面板类产品主要面向 MC 这类已经有现成服务端的游戏。

**服务器列表搜不到自己的服怎么办？**
按顺序查三件事：UDP 15637 是否放行、服务端版本是否过旧（重跑一次 steamcmd 更新）、NAT 机型的端口转发是否配置正确。这三个排完，绝大多数"搜不到"都能定位。

**预算有限，先月付还是直接年付？**
不确定能玩多久就月付。确定要长期开，年付 7 折叠加返利积分，摊到每月的成本会低不少，这也是性价比最高的买法。

开服这件事本身没什么玄学：系统选对、端口开全、内存给够，剩下就是把这台机器养下去。先按你们实际的人数买一台能稳稳跑起来的，玩上两周，你自然就知道下一台该加 CPU 主频还是加带宽。
